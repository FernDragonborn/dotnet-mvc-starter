# 2025. Переддипломний курс. Основи DevOps.

#### Вимоги до репозиторію. 
- Програмний проєкт за темою кваліфікаційної роботи бакалавра необхідно розміщувати в каталозі _**Source**_ .
- Звіт та наочні матеріали необхідно розміщувати у каталозі _**Docs**_ .
- Файл .gitignore необхідно створити самостійно або вибрати з [колекції .gitignore templates](https://github.com/github/gitignore/tree/main) в залежності від середовища розробки.
- Будь ласка, дотримуйтесь коректного іменування файлів та каталогів (див. приклади нижче).
- Корисні посилання:\
  [Теми та керівники](https://docs.google.com/spreadsheets/d/1oaOXQROkFrcoDHsU-e3ucf-C_hUiqP4tVuFmfdpH4Ag/edit?gid=0#gid=0)\
  [Шаблон звіту](https://drive.google.com/drive/folders/1rxEtuoqpwwpg4nWZ-71qTa7m8COOT1n1?usp=sharing)

#### Репозиторій. Приклад структури каталогів.
```
.\ Root of repository 
 │
 ├── Readme.md                   │ Файл-пам'ятка, яку Ви зараз читаєте. Зміни не потрібні. 
 ├── .gitignore                  │ Налаштування файлів та каталогів, які Git має ігнорувати. 
 :
 ├── Source                      │ Загальний каталог проекту або проєктів.
 │   ├── *.*                     │ Файли проекту (текст програми, база даних, конфігурація та інш.)
 │   └── Readme.md               │ Екранні форми із прикладами/тестами виконання програми з короткими поясненнями.
 :   
 └── Docs                        │ Загальний каталог з наочними матеріалами та звітом з виконаних практичних робіт. 
     ├── *.*                     │ Будь які каталоги та файли (рисунки, діаграми, скріншоти та інш.), які необхідні для звіту. 
     └── #NN GGG ПрізвищеІБ.docx │ Єдиний загальний звіт щодо виконання всіх практичних робіт.
                                 │ де NN  – дві цифри, номер останньої повністю зробленої та оформленої роботи;
                                 │    GGG – номер групи, три цифри без літер.
                                 │ Наприклад: "#02 641 ПяточкинПП.docx" - звіт з першою та другою практичними роботами Петріка П'яточкина з 641п групи.
```
